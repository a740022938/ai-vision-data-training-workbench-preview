# Known Limitations

This repository is still a preview project.
The following limitations are intentional or not fully resolved yet.

## Current limitations
- not a full production release
- training pipeline is not fully complete
- GPU monitoring is not fully implemented
- some UI windows remain under active polishing
- OpenClaw integration is currently represented by a safe preview fallback
- dependency list is intentionally lightweight and may expand later

## Why this matters
These notes help users evaluate the project honestly.
They also reduce the gap between public expectations and actual preview scope.
